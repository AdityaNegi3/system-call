# Syscall Guardian

Syscall Guardian is a React prototype for an AI-assisted system call safety console. It models role-based access to common system operations, shows a simulated execution log, and highlights policy alerts for risky calls.

## Highlights

- AI-flavored risk checks for sensitive syscall actions.
- Demo users for administrator, developer, and auditor workflows.
- Local Vite setup for quick testing in the browser.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
